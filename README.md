# Библиотека

Программа для Windows: читалка книг и фанфиков из своих папок, перевод fb2 в txt и порядок в библиотеке. Сделана
для работы с экранным диктором NVDA: всё с клавиатуры, сообщения диктор читает сам, не сбивая фокус.

## Что умеет

- **Читалка.** Библиотека из любых папок; ходить как по папкам (Enter — открыть, Backspace — назад). У книги —
  название, автор, описание, размер, главы, статус, каждое на своей строке. Главы находит сама: в fb2 — по разметке,
  в txt — по названиям глав или по отбивке; файлы при этом не меняются. Место чтения запоминается.
- **fb2 в txt** — книгой (текст как есть) или фанфиком (шапка, главы, «Конец»); файлы, папки, zip.
- **Разложить по образцу.** Программа смотрит, как разложена ваша папка (например, «Направленность\Размер» у
  фанфиков или «Автор\Цикл» у книг), и кладёт новое так же. Шаблон можно поправить или собрать самой.
- **Правка и проверки текста:** окно правки с переходом по главам, «Убрать кусочек», «Найти ссылки», пустые строки,
  метка UTF-8, мои замены, проверка всей библиотеки — всё с журналом и отменой.
- **Проверить обновления** — меню «Справка»: программа сама скачивает новую версию, проверяет подпись и
  перезапускается.

## Как поставить

Скачайте `Library.exe` из раздела [Releases](https://github.com/Tinieblas-apps/Library/releases/latest) и положите в
свою папку, например `C:\Программы\Библиотека`. Рядом программа будет держать свою папку «Данные». Python не нужен.
При первом запуске выберите папку библиотеки: меню «Настройки», «Папка библиотеки».

Файл `Library.exe.sig` — подпись: по ней программа при обновлении проверяет, что файл настоящий.
