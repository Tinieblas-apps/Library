Библиотека 0.5.1 — список клавиш

Главное окно, меню «Библиотека»:
  Ctrl+O — открыть фанфик или книгу для правки
  Ctrl+L — проверить библиотеку
  Ctrl+K — убрать кусочек
  Ctrl+J — найти ссылки
  Ctrl+M — мои замены
  Ctrl+Shift+O — разложить по образцу
  Ctrl+Shift+T — перевести fb2 в txt
  Ctrl+D — читалка
  F1 — список клавиш
  F9 — повторить последнее сообщение
  Escape — закрыть окно

Окно правки:
  F6 / Shift+F6 — следующая / предыдущая глава (диктор читает заголовок)
  Ctrl+F — найти
  F3 — найти дальше
  F7 — проверить
  Ctrl+B — пустые строки
  Ctrl+J — найти ссылки
  Ctrl+S — сохранить (для скачанного — «Готово»)
  Escape — закрыть (спросит, если правка не сохранена)

Читалка — список:
  Enter — открыть папку или книгу
  Backspace — назад, на папку выше
  Ctrl+PageDown / Ctrl+PageUp — следующая / предыдущая книга в папке
  F9 — повторить последнее сообщение
  Escape — закрыть читалку

Читалка — чтение:
  F6 / Shift+F6 — следующая / предыдущая глава («глава N из M»)
  F8 — где я: глава и сколько прочитано
  Ctrl+PageDown / Ctrl+PageUp — следующая / предыдущая книга
  Ctrl+G — сделать эту строку главой
  Ctrl+Shift+G — это не глава
  Escape — к списку (место запоминается само)

Разложить по образцу:
  Ctrl+Enter — сделать для выбранного
  Ctrl+Shift+Enter — сделать для всех
  Ctrl+Z — отменить последнее
  F9 — повторить последнее сообщение
  Escape — закрыть

Списки с галками (проверки, кусочки, ссылки, раскладка, копии):
  Пробел — поставить или снять галку
  Enter — открыть фанфик в окне правки; после правки находки пересчитываются

Сообщения программа говорит через NVDA, не сбивая фокус; F9 повторяет последнее.
